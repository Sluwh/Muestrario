# @demoneyess

Una plataforma web cibernética minimalista para organizar y visualizar las aplicaciones, utilidades y herramientas instaladas en mi sistema.

## Características

- **Categorías**: Filtrado por Desarrollo, Sistema, Multimedia, Productividad y Diseño.
- **Búsqueda instantánea**: Encuentra cualquier app por nombre o descripción.
- **Detalle interactivo**: Enlaces oficiales, características clave y atajos de teclado.
- **Diseño minimalista**: Interfaz oscura en HTML, CSS y JavaScript vanilla.

## Uso local

Solo abre `index.html` en el navegador o sírvelo con cualquier servidor local.
